# Secure DNS Platform

## Secure DNS Technology for Privacy-First Products

OpenBLD develops secure DNS infrastructure for privacy-focused products, browsers, VPN services, family-safety applications, and managed environments.

Our goal is not simply to provide another public DNS resolver.

OpenBLD is being developed as a modular DNS security platform that can add threat protection, filtering, policy enforcement, and resilient DNS infrastructure to existing products.

## Protection Before the Connection

DNS is one of the first points where potentially unwanted or malicious connections can be prevented.

A Secure DNS layer can help protect users from:

* malware infrastructure
* phishing domains
* tracking networks
* unwanted advertising infrastructure
* inappropriate or restricted content

This protection can complement security mechanisms already implemented in browsers, VPNs, applications, or endpoint products.

## Technology

The OpenBLD platform includes:

* DNS, DNS-over-HTTPS, and DNS-over-TLS
* DNSSEC validation
* malware and phishing protection
* tracker and advertising-domain filtering
* family and child-safety policies
* customizable filtering policies
* distributed resolver infrastructure
* abuse detection and rate limiting
* DNS telemetry and analytics
* network-level DDoS protection

The components can be used together or integrated as part of a larger product architecture.

## Integration Models

### Hosted

Secure DNS infrastructure operated as part of the OpenBLD network.

### Dedicated

A dedicated DNS environment for a specific partner, product, or user base.

### Partner Infrastructure

OpenBLD technology deployed within infrastructure controlled by the partner.

This model allows organizations to retain control over traffic, infrastructure, operational policies, and data handling while adding OpenBLD resolver, filtering, and security technologies.

## Potential Applications

### Browser Secure DNS

An optional secure DNS mode providing domain-level malware, phishing, and tracker protection.

### VPN DNS Protection

DNS-level threat and privacy protection integrated into an existing VPN service.

### Family and Junior Products

Additional DNS policy enforcement for products designed for children and families.

### Privacy-Focused Applications

Encrypted DNS infrastructure that reduces reliance on large third-party public resolvers.

### Managed and Enterprise Environments

Custom DNS policies, filtering, telemetry, and security controls for managed networks.

## Exploring Cooperation

We do not assume that every product needs a new DNS provider or that existing DNS infrastructure should be replaced.

We are interested in exploring whether OpenBLD technology could complement existing privacy and security products as an additional DNS security layer.

Cooperation could range from a small technical experiment or pilot to dedicated infrastructure or deeper technology integration.

If your team is working on Secure DNS, DNS filtering, privacy, or DNS-level threat protection, we would be happy to exchange ideas.
