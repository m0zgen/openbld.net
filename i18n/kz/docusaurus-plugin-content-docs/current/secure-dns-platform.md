# Secure DNS платформасы

## Құпиялыққа бағытталған өнімдерге арналған Secure DNS технологиясы

OpenBLD құпиялыққа бағытталған өнімдер, браузерлер, VPN сервистері, отбасылық қауіпсіздік қолданбалары және басқарылатын орталар үшін қауіпсіз DNS инфрақұрылымын дамытады.

Біздің мақсатымыз — тағы бір жалпыға қолжетімді DNS резолверін ұсыну ғана емес.

OpenBLD қолданыстағы өнімдерді қауіптерден қорғау, сүзгілеу, саясаттарды қолдану және тұрақты DNS инфрақұрылымымен толықтыра алатын модульдік DNS қауіпсіздік платформасы ретінде дамып келеді.

## Қосылым орнатылғанға дейінгі қорғаныс

DNS — ықтимал қажетсіз немесе зиянды қосылымды ерте кезеңде тоқтатуға болатын алғашқы деңгейлердің бірі.

Secure DNS деңгейі пайдаланушыларды мыналардан қорғауға көмектесе алады:

* зиянды инфрақұрылымнан
* фишингтік домендерден
* қадағалау желілерінен
* қажетсіз жарнамалық инфрақұрылымнан
* орынсыз немесе шектелген контенттен

Мұндай қорғаныс браузерлерде, VPN сервистерінде, қолданбаларда немесе соңғы құрылғыларды қорғау жүйелерінде бұрыннан бар қауіпсіздік механизмдерін толықтыра алады.

## Технологиялар

OpenBLD платформасына мыналар кіреді:

* DNS, DNS-over-HTTPS және DNS-over-TLS
* DNSSEC тексеруі
* зиянды және фишингтік домендерден қорғау
* трекерлер мен жарнамалық домендерді сүзгілеу
* отбасылық және балалар қауіпсіздігі саясаттары
* бапталатын сүзгілеу саясаттары
* таратылған DNS резолвер инфрақұрылымы
* теріс пайдалануды анықтау және сұраулар жиілігін шектеу
* DNS телеметриясы және аналитика
* желілік деңгейдегі DDoS қорғанысы

Компоненттер бірге пайдаланылуы немесе үлкенірек өнім архитектурасының бір бөлігі ретінде интеграциялануы мүмкін.

## Интеграция модельдері

### Hosted

OpenBLD желісінің құрамында жұмыс істейтін Secure DNS инфрақұрылымы.

### Dedicated

Белгілі бір серіктеске, өнімге немесе пайдаланушылар тобына арналған жеке DNS ортасы.

### Серіктес инфрақұрылымы

OpenBLD технологиялары серіктес басқаратын инфрақұрылым ішінде орналастырылуы мүмкін.

Бұл модель ұйымдарға трафикті, инфрақұрылымды, операциялық саясаттарды және деректерді өңдеуді бақылауды өзінде сақтай отырып, OpenBLD резолвинг, сүзгілеу және қауіпсіздік технологияларын пайдалануға мүмкіндік береді.

## Ықтимал қолдану сценарийлері

### Браузерлерге арналған Secure DNS

Зиянды, фишингтік және қадағалау домендерінен қорғауды қамтамасыз ететін қосымша қауіпсіз DNS режимі.

### VPN үшін DNS қорғанысы

Қолданыстағы VPN сервисіне интеграцияланған DNS деңгейіндегі қауіптерден қорғау және құпиялықты арттыру.

### Отбасылық және балаларға арналған өнімдер

Балалар мен отбасыларға арналған өнімдер үшін DNS саясаттарын қосымша қолдану.

### Құпиялыққа бағытталған қолданбалар

Ірі үшінші тараптың жалпыға қолжетімді DNS резолверлеріне тәуелділікті азайтатын шифрланған DNS инфрақұрылымы.

### Басқарылатын және корпоративтік орталар

Басқарылатын желілерге арналған жеке DNS саясаттары, сүзгілеу, телеметрия және қауіпсіздік құралдары.

## Ынтымақтастық мүмкіндіктері

Біз әрбір өнімге жаңа DNS провайдері қажет немесе қолданыстағы DNS инфрақұрылымын міндетті түрде ауыстыру керек деп есептемейміз.

Бізге OpenBLD технологиясы қолданыстағы құпиялық және қауіпсіздік өнімдерін қосымша DNS қауіпсіздік деңгейі ретінде толықтыра ала ма деген бағытты зерттеу қызықты.

Ынтымақтастық шағын техникалық эксперименттен немесе пилоттық жобадан басталып, жеке инфрақұрылымға немесе тереңірек технологиялық интеграцияға дейін дами алады.

Егер сіздің командаңыз Secure DNS, DNS сүзгілеу, құпиялық немесе DNS деңгейіндегі қауіптерден қорғау бағыттарында жұмыс істесе, біз идеялармен алмасуға қуаныштымыз.
