# OpenBLD Плюс

Бұл барынша терең талдау және DNS трафик статистикасын жинау үшін  OpenBLD.net  пайдалана алатын кәсіби тармақ.
[Демеушіліктен](/docs/sponsorship/) немесе [Қайырымдылық көмектен](/docs/donation/) кейін [Пайдалану ережелеріне](/docs/overwiew/how-it-works/#пайдалану-ережелеріне) сәйкес қолжетімді болады.

## OpenBLD+ артықшылықтары

- [x] Жеке қолдау.
- [x] Сіздің компанияның домені үшін айқын ақ тізім.
- [x] Сіздің логотип немесе никнейм [Үй парақшасында](https://openbld.net)
- [x] OpenBLD.net DNS пайдаланушылары үшін сіздің доменнің деректерін жылдамдатып жеткізу.
- [x] Кері байланыс немесе Сізге қажет болса, біздің атымыздан алғыс хат.
- [x] Сіздің компанияңызды ілгерілетуде және ұсынымдарда көмек көрсету.
- [x] Сіздің компания үшін IP DNS.

## Кеңейтілген мүмкіндіктер

Өткізу қабілетін үнемдеу және ақпараттық қауіпсіздік қауіптерін азайту үшін OpenBLD.net сайтын пайдаланғысы келетін шағын, орта және ірі компаниялар үшін өте қолайлы.

- [x] Сіздің қажеттіліктеріңізге толық теңшеу және реттеу
- [x] Рұқсат етілген/бұғатталған домендердің бірегей тізімдері ([Мысал](https://github.com/m0zgen/my-zbld))
- [x] Айына ~1+ Миллион сұрау салуға дейін
- [x] DNSSEC, TLSv1.2, TLSv1.3
- [x] Журналды біріктіру, соның ішінде журналдарды серверге/syslog/SIEM жүйесіне жіберу мүмкіндігі
- [x] Жеке қолдау

:::note
Шарттар жеке-жеке келіссөздер жүргізіледі.
:::
