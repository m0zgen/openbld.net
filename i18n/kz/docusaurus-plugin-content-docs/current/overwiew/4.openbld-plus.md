# OpenBLD Плюс

Бұл барынша терең талдау және DNS трафик статистикасын жинау үшін  OpenBLD.net  пайдалана алатын кәсіби тармақ.
[Демеушіліктен](/docs/sponsorship/) немесе [Қайырымдылық көмектен](/docs/donation/) кейін [Пайдалану ережелеріне](/docs/overwiew/how-it-works/#пайдалану-ережелеріне) сәйкес қолжетімді болады.

- [x] Жеке қолдау.
- [x] Сіздің компанияның домені үшін айқын ақ тізім.
- [x] Сіздің логотип немесе никнейм [Үй парақшасында](https://openbld.net)
- [x] OpenBLD.net DNS пайдаланушылары үшін сіздің доменнің деректерін жылдамдатып жеткізу.

- [x] Сіздің компанияңызды ілгерілетуде және ұсынымдарда көмек көрсету.
