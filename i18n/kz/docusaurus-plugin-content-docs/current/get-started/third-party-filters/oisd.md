# OISD

## Блоклист дегеніміз не [oisd](https://oisd.nl/)?

Бұл блоклист сіздің құрылғыларыңызға қажет емес немесе зиянды домендерге қосылуға мүмкіндік бермейді.
Бұл жарнамалар санын азайтады, зиянды БЖ қаупін төмендетеді және құпиялылықты арттырады.

## OpenBLD.net-те (RIC) OISD қалай пайдалануға болады

Сіз OpenBLD.net-те [OISD](https://oisd.nl/) `RIC` режиміндегі `DoH` сілтеме ретінде пайдалана аласыз:

```shell
https://ric.openbld.net/dns-query/oisd
```

:::tip
- [OISD](https://oisd.nl/) қалай бар сол күйінде – ерекшеліктерсіз, қосымша қара тізімсіз пайдаланылады – тек OISD.
- OpenBLD.net әр 1 сағат сайын жаңартылып отыратын «шағын» OISD тізімін пайдаланады.
:::
