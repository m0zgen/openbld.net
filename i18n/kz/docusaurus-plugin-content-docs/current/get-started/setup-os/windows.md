# Windows

Windows желісінің баптауларында OpenBLD.net баптау

1. "Іске қосу" мәзірін ашыңыз, компонент белгішесін таңдаңыз.
2. "Баптаулар" терезесінде "Желі және Интернетті" таңдаңыз.
3. Ethernet > Желіні басыңыз.
4. IP баптауларын өзгерту үшін басыңыз.
5. DNS баптауларын өзгертіңіз.

## Қосымша сілтемелер

* Windows 11-де қалай [HTTPS арқылы DNS қосуға болады](https://www.howtogeek.com/765940/how-to-enable-dns-over-https-on-windows-11/).
