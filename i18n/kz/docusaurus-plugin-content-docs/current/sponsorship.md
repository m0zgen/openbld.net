# Демеушілік

Қолдаудың бір немесе бірнеше әдісін таңдаңыз:

- [x] Өтеусіз демеушілік қолдау / [Donation](/docs/donation)
- [x] Ресурстарды (серверлер, сервистер, лицензиялар және т.б.) ұсыну
- [x] Идеялар бар ма? Маған [Байланыс деректері](/docs/contacts/) парақшасы арқылы хабарласуыңызды өтінемін

## Артықшылықтары

Демеушілік қолдау көрсеткеннен кейін Сіз кеңейтілген [OpenBLD Plus](/docs/overwiew/openbld-plus) функционалын сұрата аласыз.
