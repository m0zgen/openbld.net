# Демеушілік

Жобаның, оның жол картасының өсуі мен дамуы үшін,
Сервис қаржыландыруды және демеушілік көмекті қажет етеді.

Қолдаудың бір немесе бірнеше әдісін таңдаңыз:
- [x] Өтеусіз демеушілік қолдау
- [x] Өзіңіздің OpenBLD.net [OpenBLD+](/docs/overwiew/openbld-plus/#openbld-benefits) дейін кеңейтіңіз
- [x] Ресурстарды (серверлер, сервистер, лицензиялар және т.б.) ұсыну
- [x] Адам ресурстарын (бағдарламалау, маркетинг, инженерия жөніндегі мамандар және т.б.) ұсыну
- [x] Идеялар бар ма? Маған [Байланыс деректері](/docs/contacts/) парақшасы арқылы хабарласуыңызды өтінемін
