# OpenBLD Плюс

Профессиональная ветка OpenBLD движка - для глубокого анализа, сбора метрик, статистики и фильтрации вредоносного DNS трафика.

## Преимущества OpenBLD+

- [x] Персональная поддержка.
- [x] Явный белый список для домена Вашей компании.
- [x] Ваш логотип или никнейм на [Домашней странице](https://openbld.net)
- [x] Ускоренная доставка данных вашего домена для пользователей OpenBLD.net DNS.
- [x] Обратная связь или благодарственное письмо, если оно Вам нужно от нас.
- [x] Помощь в продвижении и рекомендации вашей компании.
- [x] IP DNS для вашей компании.

## Расширенные возможности

Идеально подходит для малых, средних и крупных компаний, желающих использовать OpenBLD.net для экономии трафика и снижения информационных угроз.

- [x] Полная кастомизация и настройка под ваши потребности
- [x] Уникальные списки разрешенных/блокируемых доменов ([Пример](https://github.com/m0zgen/my-zbld))
- [x] До ~1 Миллиона запросов в месяц
- [x] DNSSEC, TLSv1.2, TLSv1.3
- [x] Агрегация журналов, включая возможность отправки журналов на ваш сервер / syslog / SIEM
- [x] Персональная поддержка

:::note
Доступна для корпоративных клиентов и организаций, использующих OpenBLD.net в своих целях. Для получения дополнительной информации свяжитесь с нами через [Контакты](/docs/contacts).
:::
