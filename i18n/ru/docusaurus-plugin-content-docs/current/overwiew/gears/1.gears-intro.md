# Что такое Шестерни OpenBLD.net?

OpenBLD.net Gears - это набор технологий и сервисов, предоставляемых OpenBLD.net для улучшения производительности, безопасности и конфиденциальности.

## Шестерни

### Система управления

- **zBLD - Zero-Trust BlockList DNS**: DNS-серверы нулевого доверия с расширенными функциями фильтрации, безопасности, конфиденциальности.
- **zLB - zBLD Load Balancer**: Балансировщик нагрузки для zBLD DNS-серверов.
- **benZine**, **Cactusd**: Сервисы дистрибуции компонентов OpenBLD.net Gears.

## Дополнительная информация

:::important
* Это собственные внутренние технологии и сервисы OpenBLD.net, которые могут предоставляться пользователям как услуга в режиме [OpenBLD Plus](/docs/overwiew/openbld-plus/).
* Не все технологии доступны для публичного использования.
* Эти технологии **не используются** в публичных сервисах:
  * нет метрик
  * нет логов (см. _Как это работает_)
  * нет сбора данных
  * нет продажи данных
  * нет аналитики
  * нет центрального хранилища данных
  * нет агрегации данных
  * см. [How it works](/docs/overwiew/how-it-works/) для дополнительной информации
:::
