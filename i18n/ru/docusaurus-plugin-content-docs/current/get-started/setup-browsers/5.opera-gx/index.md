# Opera GX

Настройка OpenBLD.net в Opera GX:

1. Настройки > Браузер
2. Включить `Использовать DNS поверх HTTPS вместо системных настроек DNS`
3. Указать адрес:

```shell
https://ada.openbld.net/dns-query
```
